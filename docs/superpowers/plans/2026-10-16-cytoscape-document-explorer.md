# Cytoscape 문서 펼치기 구현 계획

승인 기준: 대화에서 검토한 `outputs/map-comparison`의 Cytoscape 문서 펼치기 시안.

- [x] 원문 기반 항목 추출: GFM 표의 요구사항/기능 ID·API 메서드와 경로, 목록, 제목을 원문 순서와 행·revision 근거로 연결. 코드 블록의 가짜 표는 제외. 문서 유형 추론과 기획 문서 필터는 표시 전용. 동일 본문 원본·사본 묶기는 선택 사항.
- [x] Cytoscape 캔버스: 고정 프로젝트 기준 → 문서 → 선택 문서 항목. 한 문서만 펼치고 재클릭 시 접기. 원문 순서로 8개씩 표시. 펼치기·페이지 전환 시 문서 위치와 뷰포트 보존. 항목 상세는 카드 옆에 배치하고 공간 부족 시 반대편으로 전환.
- [x] 기존 React Markdown으로 상세 표시: 제목·목록·표·코드 블록, 원문 이동, 닫기/Esc/배경 클릭. 외부 HTML·이미지 실행 방지. 원문 변경 시 오래된 상세를 닫는다.
- [x] ProjectGraph 기본 화면으로 통합. 기존 관계 편집/연결/AI 검토 기능은 연결 탐색 모드로 유지. 기존 저장 레이아웃과 문서는 변경하지 않는다. 기존 E2E는 연결 탐색을 명시적으로 선택.
- [x] 원문 추출·좌표/배선 단위 테스트, 캔버스 클릭/접기/상세/원문 이동/작은 화면 E2E. lint, typecheck, 단위 테스트, 빌드, 전체 E2E 검증 후 PR.

검토 초점: CRLF·이스케이프 파이프·코드 블록, ID 없는 일반 문서, 실제 문서 제목 및 임의 ID의 충돌, 다수 문서/항목 가독성, 외부 문서 수정 후 상세 원문 일치.

브랜치 기준: PR #41이 병합된 main(3a8e758)에서 시작. 이슈 #42, 브랜치 feat/42-cytoscape-document-explorer.

검토 보완: ID 접미사 보존, API 색인보다 하위 요청·응답 전체 우선, 키보드 포커스 카드 드러내기, 아래쪽 문서 옆 항목 배치. 각각 실패를 재현한 회귀 테스트로 검증한다.

검증 결과: lint · format:check · typecheck · build 통과, 단위/통합 174 통과(조건부 6 제외), 전체 Electron E2E 23 통과. 독립 검토의 세 보완 사항은 회귀 테스트로 해결했다.
