## 검증 중 보완과 제한

패키징된 앱에서는 개발용 가짜 Codex 실행 옵션을 받지 않는다. 최초 검증에서 합성 문장 한 건이 실제 Codex 경로에 전달됐으며 개인 문서는 포함하지 않았다. 이 실행을 성공 검증으로 집계하지 않았다. 이후 검증은 임시 데이터와 가짜 Claude 응답으로 수행하며 main의 fetch를 대체해 생성 요청의 실제 네트워크 전송을 차단했다. 실제 AI 응답 품질은 이 검증의 대상이 아니다.

일반 복사 중 디스크 여유 공간 부족으로 임시 앱 생성이 중단됐으나 기존 설치 앱은 교체 전 상태로 남았다. 이번 작업의 중복 복사본과 실패한 임시 앱만 정리하고 APFS 복제를 사용했다. SQLite는 원본 파일을 읽기 복사한 뒤 로컬 사본에서 WAL을 처리해 백업했으며 사용자 DB를 직접 수정하지 않았다.

문서 전용 변경이므로 이전 기능 PR의 전체 테스트를 반복하지 않았다. 기능 기준 PR #47의 macOS·Windows CI와 제목 검사는 통과했으며 이번에는 실제 설치 산출물의 무결성과 시작·저장·수락 동작을 별도로 확인했다. 개발자 서명·공증, 자동 업데이트 및 GitHub Release 공개 배포는 수행하지 않았다.
